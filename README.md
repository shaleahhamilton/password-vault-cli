## About This Project

This is a beginner-friendly Password Vault built in Python.  
It runs in the command line and lets you:

- Register a username and master password
- Log in with secure credential check
- Save passwords for websites/apps
- View saved passwords later
- Store data in files so it persists

> This is a learning project — not secure for real password storage yet.
